[003]STANDALONE · AI DOCUMENT EXTRACTION● Public repo

Resibo

Invoice & receipt PDFs to a checked spreadsheet

Bookkeepers still key Philippine invoices in by hand. Resibo reads a multi-page PDF with Claude, then Python checks every number and flags the rows a person should look at. The model reads; Python decides.

PDF→Claude, structured output→Validation→Excel / CSV
  • Finds every document in a PDF and returns one row each plus line items
  • Decimal money rules for totals, 12% VAT, duplicates, TINs and dates mark rows OK, REVIEW or ERROR
  • 100% of fields correct on an 8-document eval set, about $0.01 a page, with a daily budget cap
  • Web page, HTTP API, CLI and an n8n workflow from Google Drive to Google Sheets
